# Exercícios de Python

Repositório com exercícios introdutórios de **Python**, organizados por aula. Os ficheiros são pequenos programas independentes que praticam conceitos fundamentais de programação, como variáveis, tipos de dados, operações matemáticas, leitura de dados e estruturas condicionais.

## Conteúdos

| Ficheiro | Tema / o que o programa faz |
|---|---|
| `aula_01.py` | Apresentação simples com mensagens no terminal e utilização de `print()`. |
| `aula_02.py` | Declaração de variáveis e utilização de diferentes tipos de dados (`str`, `int`, `float` e `bool`). |
| `aula_03.py` | Operações aritméticas e operadores de comparação. |
| `aula_04.py` | Recolha de nomes e idades, cálculo da soma e da média das idades. |
| `aula_05.py` | Leitura de dois números inteiros e cálculo da soma. |
| `aula_06.py` | Leitura de dois números e cálculo de uma potência. |
| `aula_07.py` | Conversão de uma quantidade de segundos em horas, minutos e segundos restantes. |
| `aula_08.py` | Recolha do nome, módulo e notas de duas provas; cálculo da soma e da média das notas. |
| `aula_15.py` | Cálculo do pagamento com remuneração normal até 40 horas e valor acrescido para horas extra. |
| `aula_16.py` | Verificação se uma pontuação está dentro do intervalo de 0 a 1. |
| `aula_17.py` | Verificação do limite de velocidade e cálculo de uma multa quando a velocidade ultrapassa 80 km/h. |
| `aula_18.py` | Identificação do maior e do menor de três números. |
| `aula_19.py` | Cálculo do aumento salarial de acordo com o valor do salário. |
| `aula_20.py` | Cálculo do preço de uma passagem em função da distância pretendida. |

## Requisitos

- Python 3 instalado.
- Um terminal ou editor de código, como o Visual Studio Code.

Não são necessárias bibliotecas externas: os exercícios utilizam funcionalidades incluídas no Python.

## Como executar

1. Clona ou descarrega este repositório.
2. Abre a pasta do projeto num terminal.
3. Executa o ficheiro pretendido com Python 3. Por exemplo:

```bash
python aula_01.py
```

Em alguns sistemas, o comando pode ser `python3`:

```bash
python3 aula_01.py
```

Os programas que utilizam `input()` vão pedir dados no terminal. Introduz os valores solicitados para ver o resultado.

## Conceitos praticados

- Saída de informação com `print()`.
- Entrada de dados com `input()`.
- Variáveis e tipos de dados.
- Conversão de valores com `int()` e `float()`.
- Operadores aritméticos e de comparação.
- Cálculo de somas, médias, potências e conversões de unidades.
- Estruturas condicionais: `if`, `elif` e `else`.
- Formatação de texto com f-strings.

## Nota

Cada ficheiro pode ser executado individualmente. Os exercícios estão organizados por número de aula e não precisam de ser executados em conjunto.
