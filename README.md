# 📚 Exercícios de Programação em Python

## 📌 Sobre o projeto

Este repositório reúne uma coleção de exercícios práticos desenvolvidos em Python, com o objetivo de aprender e praticar os fundamentos da programação.

Os exercícios trabalham conceitos como variáveis, operações matemáticas, entrada e saída de dados, conversão de tipos e estruturas condicionais.

## 🗂️ Exercícios realizados

| Ficheiro | Descrição |
|---|---|
| `aula_09.py` | Verificação de números pares através do resto da divisão por 2. |
| `aula_10.py` | Conversão de temperaturas de Celsius para Fahrenheit. |
| `aula_11.py` | Cálculo da área e do perímetro de um retângulo. |
| `aula_13.py` | Utilização de condições para apresentar mensagens de acordo com a idade. |
| `aula_14.py` | Cálculo do pagamento de horas trabalhadas, incluindo horas extras. |
| `aula_15.py` | Cálculo das despesas mensais e contagem dos itens considerados. |

## 🛠️ Tecnologias utilizadas

- **Python 3**
- Visual Studio Code (ou outro editor de código)
- Terminal / Linha de comandos

## ▶️ Como executar os exercícios

1. Clonar ou descarregar este repositório.
2. Abrir a pasta do projeto no editor de código.
3. Escolher o exercício que pretende executar.
4. Abrir o terminal na pasta do projeto.
5. Executar o seguinte comando:

```bash
python nome_do_ficheiro.py
```

Por exemplo:

```bash
python aula_09.py
```

## 🎯 Objetivos de aprendizagem

- Compreender a utilização de variáveis.
- Trabalhar com diferentes tipos de dados (`int`, `float` e `str`).
- Utilizar a função `input()` para receber dados do utilizador.
- Apresentar resultados com `print()`.
- Realizar operações matemáticas.
- Aplicar estruturas condicionais (`if`, `elif` e `else`).
- Desenvolver o raciocínio lógico e a capacidade de resolução de problemas.

## 📈 Conclusão

Este projeto representa a evolução da aprendizagem dos fundamentos da linguagem Python, através de exercícios práticos e progressivos.

Cada exercício contribui para desenvolver competências essenciais para a programação e serve como base para projetos mais avançados no futuro.
